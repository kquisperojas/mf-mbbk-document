1. Visión general

Guía corta del Portal MBBK: documentación de iniciativas de Canales Digitales en un solo lugar.

Qué es el portal

Concentra informes HTML a partir de Jira, DET, diagramas y pruebas. No sustituye Jira ni GitHub: toma datos de ahí, los deja para leer, compartir y descargar en Word.

  • Ciclo: Borrador → En revisión → Publicada. Si faltan diagramas o pruebas queda Desactualizada.
  • Todos consultan, generan y comentan. Solo el autor edita o borra su comentario. Solo el líder técnico aprueba y publica. Solo el administrador gestiona usuarios.

Estados

EstadoSignifica
BorradorHay insumos y aún no se generó el informe. Se continúa en Generar.
En revisiónInforme con DET, diagramas y pruebas. El líder técnico comenta o publica.
PublicadaEl líder técnico aprobó. Lista para el squad.
DesactualizadaHay informe, pero faltan diagramas o pruebas. Regenerar con esos adjuntos.

Módulos de Documentación del portal

Cinco pantallas del menú izquierdo. La búsqueda admite código (NEG/APP), título o responsable, según la pantalla.

  1. Visión general. Esta guía. Para qué está cada módulo y qué pantalla abrir. No genera archivos.
  2. Ficha de iniciativa. Contrato del informe: Iniciativa (negocio), Solución (implementación), Diagramas y Pruebas. Referencia antes de generar o revisar.
  3. Ficha de microservicio. MS citados en informes ya generados y los códigos NEG/APP que los usan. El buscador filtra por nombre de microservicio o código; el código abre el informe.
  4. Generar documentación. Épicas Solucionadas de Jira. DET obligatorio. Guardar borrador o generar el HTML. Con diagramas y pruebas queda En revisión; si faltan, Desactualizada. La lista se busca por clave, título o responsable.
  5. Administrar documentación. Filtra por estado. Modificar abre el editor de las 4 secciones; Eliminar pide confirmación. Un borrador se retoma en Generar.

Qué abrir

Consultar

  • Estado de un NEG → Dashboard o Iniciativas
  • Contacto del squad → Squad
  • MS citado en un NEG → Ficha de microservicio
  • Repo GitHub → Catálogo MS

Producir

  • Épica Solucionada + DET → Generar (o Guardar borrador)
  • Corregir contenido → Administrar
  • Observaciones o publicar → informe, pestaña Iniciativa

Informe

Iniciativa (negocio y observaciones), Solución (implementación), Diagramas y Pruebas. Compartir copia la URL del portal con la sección. Aprobar y Publicar solo lo confirma el líder técnico cuando el estado es En revisión.
